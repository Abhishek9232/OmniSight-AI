# OmniSight-AI

AI-Assisted Online Examination & Behavioral Integrity Monitoring System

## Project Status

🚧 Currently in Phase 0 — Research & Project Definition

## Objective

OmniSight-AI is a final-year academic project focused on developing an online examination system with basic AI-assisted behavioral monitoring and machine-learning-based integrity risk analysis.

## Current Technology Direction

- Python
- Streamlit
- MySQL
- Pandas
- NumPy
- Scikit-learn
- OpenCV
- Git & GitHub

## Development Approach

The project will be developed phase by phase:

1. Research & Project Definition
2. Requirement Analysis
3. System Design
4. Development Environment & Git
5. Database Implementation
6. Authentication & User Management
7. Core Examination System
8. Proctoring / Computer Vision
9. Behavioral Data & Feature Engineering
10. Machine Learning
11. Explainable Integrity Dashboard
12. Integration, Testing & Documentation
